# advlab

โปรเจกต์ตัวอย่างสำหรับรายวิชา ประกอบด้วยโปรแกรมดาวน์โหลดวิดีโอ/เสียงจาก YouTube

## ไฟล์ในโปรเจกต์

- `dlyoutube.py` — โปรแกรมดาวน์โหลดวิดีโอหรือไฟล์เสียงจาก YouTube โดยใช้ไลบรารี `yt-dlp`

## การติดตั้ง

ต้องติดตั้งไลบรารีที่จำเป็นก่อนใช้งาน:

```
pip install yt-dlp
```

หากต้องการดาวน์โหลดเฉพาะเสียง (audio-only) ต้องมี `ffmpeg` ติดตั้งอยู่ในเครื่องด้วย เพื่อใช้แปลงไฟล์เป็น mp3

## วิธีใช้งาน

รันโปรแกรม แล้วทำตามคำถามที่ปรากฏบนหน้าจอ:

```
python dlyoutube.py
```

โปรแกรมจะถามข้อมูลทีละขั้นตอน:

1. **กรุณาใส่ลิงก์วิดีโอ YouTube** — วางลิงก์วิดีโอที่ต้องการดาวน์โหลด
2. **ต้องการดาวน์โหลดแบบใด?**
   - พิมพ์ `1` เพื่อดาวน์โหลดวิดีโอ (ค่าเริ่มต้น)
   - พิมพ์ `2` เพื่อดาวน์โหลดเฉพาะไฟล์เสียง (mp3)

ไฟล์ที่ดาวน์โหลดจะถูกบันทึกไว้ในโฟลเดอร์ `downloads`
